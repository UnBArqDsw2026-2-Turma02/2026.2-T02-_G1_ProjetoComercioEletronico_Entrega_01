**Universidade de Brasília (UnB)**

## 📌 Sobre o Projeto

Este repositório contém a documentação e os artefatos específicos da **etapa Base** desenvolvidos pelo **Grupo 01** para o projeto de **Comércio Eletrônico**, com ênfase em Design Centrado no Usuário e Usabilidade / UX. 

O conteúdo aqui presente serve como a fundação do projeto, contemplando, além dos artefatos obrigatórios da entrega mínima (Rich Picture/Mapa Mental, SIG na notação NPR, Modelo do fluxo de software na notação BPMN, usando Engenharia Reversa) levantamentos iniciais, relatórios das subequipes, tabela de participação individual e atas de reuniões que estruturam as decisões arquiteturais da aplicação.
