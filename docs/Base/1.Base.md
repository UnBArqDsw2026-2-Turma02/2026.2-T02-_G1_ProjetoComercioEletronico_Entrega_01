# 1. Desenho de Software (Base)

Esta página reúne os principais artefatos desenvolvidos para a **Alltletic**, organizando os diferentes modelos e representações produzidos ao longo da entrega 1. O objetivo é centralizar esses artefatos e proporcionar uma visão integrada das decisões de análise, modelagem e desenho da solução.

Os materiais apresentados contemplam diferentes perspectivas do sistema, permitindo compreender sua estrutura, seus requisitos e as relações entre os elementos que compõem a plataforma.
