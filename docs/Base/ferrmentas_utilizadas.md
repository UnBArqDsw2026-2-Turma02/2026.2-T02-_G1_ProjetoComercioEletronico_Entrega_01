## Ferramentas Utilizadas

Durante o desenvolvimento do projeto **Allthetic**, foram utilizadas diferentes ferramentas para apoiar a comunicação, organização, modelagem, documentação, desenvolvimento, versionamento e planejamento das atividades da equipe.

**Tabela 1:** Ferramentas utilizadas no projeto

| **Ferramenta** | **Nome** | **Uso no projeto** |
| :---: | --- | --- |
| <img src="https://cdn.simpleicons.org/whatsapp" width="50" height="50"> | **WhatsApp** | Utilizado para comunicação rápida entre os integrantes da equipe, compartilhamento de informações, alinhamento de atividades e organização das tarefas do projeto. |
| <img src="https://cdn.simpleicons.org/microsoftteams" width="50" height="50"> | **Microsoft Teams** | Utilizado para realização de reuniões, discussões entre os integrantes e acompanhamento das atividades relacionadas ao projeto. |
| <img src="https://cdn.simpleicons.org/miro" width="50" height="50"> | **Miro** | Utilizado para colaboração visual, organização de ideias, elaboração de diagramas e construção coletiva dos artefatos do projeto. |
| <img src="https://cdn.simpleicons.org/microsoftexcel" width="50" height="50"> | **Microsoft Excel** | Utilizado para organização de informações, elaboração de tabelas, planejamento e acompanhamento das atividades da equipe. |
| <img src="https://cdn.simpleicons.org/googledocs" width="50" height="50"> | **Google Docs** | Utilizado para elaboração colaborativa de documentos, registros, textos e materiais relacionados ao projeto. |
| <img src="https://cdn.simpleicons.org/visualstudiocode" width="50" height="50"> | **Visual Studio Code** | Utilizado como ambiente de desenvolvimento para edição dos arquivos Markdown, HTML, SVG e demais arquivos utilizados na construção da documentação do projeto. |
| <img src="https://cdn.simpleicons.org/github" width="50" height="50"> | **GitHub** | Utilizado para versionamento, armazenamento e gerenciamento dos arquivos do projeto, além da publicação da documentação por meio do GitHub Pages. |
| <img src="https://cdn.simpleicons.org/when2meet" width="50" height="50"> | **When2meet** | Utilizado para identificar os horários disponíveis dos integrantes da equipe e facilitar o agendamento de reuniões e encontros. |

*Fonte: [Dylan Cavalcante](https://github.com/dylancavalcante).*
